# Privacy-sanitized source publication

This repository starts from one source snapshot. Original Git history, author
metadata, PR discussions and Actions logs were not imported. The original
repository remains a private archive; its commit references are historical.

Personal operator labels and example account addresses were generalized.
One frozen diagnostic configuration contained a personal operator label in its
Windows instructions. Its public copy has a new checksum; dependent source pins
were updated to the exact public bytes without weakening validation. The
generation parameters, prompts, schemas, scorer and fixture bytes were preserved.

Historical measurements belong to the original private commits and checksums.
They are not measurements of this privacy-sanitized revision. No model was run
for publication. Existing freeze_commit fields identify historical preregistration;
they are not public checkout instructions. Old Windows command blocks that clone
the private archive still require access to that archive and must not be retargeted
by replacing the repository URL alone. Recover old reports from the private archive.

Before any new real inference, freeze and review a new public execution commit/tree
and provide complete manual Windows instructions. Do not retry old experiments
merely to migrate this repository. Normal mock tests remain offline.

Use a pseudonym for BOTH Git author and committer names, plus an appropriate
GitHub noreply email. Inspect all outgoing commits and message trailers before
pushing; do not merge or cherry-pick private history into this repository.
GitHub account ownership and public profiles remain visible. A noreply email
does not hide a real name or anonymize the account.

Current open work from the private archive is not included unless separately
reviewed and imported as a clean change with sanitized commit identities.
